Existing platforms rate buildings; students rent rooms. **Trojan Rooms** is a Next.js 15 + Postgres + Drizzle ORM application that ingests room-level reviews along eight axes — light, noise, HVAC, plumbing, kitchen, commute, safety, building age — and serves ranked listings via a hybrid recommender.

## Architecture

Item-item cosine on rating vectors merges with a content score over amenity embeddings (`text-embedding-3-small`, stored in pgvector). Search hits a Redis-cached top-k before falling through to Postgres, holding **p50 latency at 220 ms** across the 7-neighborhood corpus around USC.

Authentication uses `@usc.edu` magic-link via NextAuth + Resend to keep the review pool gated. An upvote-weighted Bayesian average smooths cold-start listings with fewer than 5 reviews — without it, a single 5-star review from a friend would flatten the rank distribution.

```ts
// Hybrid score = alpha * collab + (1 - alpha) * content
function score(listing: Listing, userVec: number[]) {
  const collab = cosine(listing.ratingVector, userVec);
  const content = dot(listing.amenityEmbed, userPrefEmbed);
  return ALPHA * collab + (1 - ALPHA) * content;
}
```

## What I'd do differently

- Swap pgvector for a dedicated vector store once review volume crosses ~50k.
- Pre-compute neighborhood embeddings nightly instead of on-demand.
- Add a "lived-here" badge that requires lease verification — would eliminate the small but real review-spam vector.
